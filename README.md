# Palsir CZ — сайт

## Структура

| Файл | Що це |
|---|---|
| `index.html` | Головна — про компанію |
| `robota.html` | Вакансія на заводах у Кадані та Хомутові |
| `firmam.html` | Для компаній: агентурне працевлаштування, ціни |
| `dokumenty.html` | Для іноземців: робоча карта, віза, ПМП |
| `kontakt.html` | Контакти, реквізити, мапа |
| `privacy.html` | Політика обробки персональних даних |
| `style.css` | Усі стилі. Кольори — угорі, у блоці `:root` |
| `common.js` | Контакти, іконки, форма, меню, переклади шапки й футера |
| `workers.webp` / `workers.jpg` | Фото для сторінки вакансії |

Усі файли лежать в одній папці, у корені репозиторію.
Папка `img/` — поруч із ними.

## Зображення

У папці `img/` уже лежать:

| Файл | Де використовується |
|---|---|
| `foto-agentura` | головна, шапка |
| `foto-prideleni` | компаніям, «Тимчасове призначення» |
| `foto-jaktofunguje` | компаніям, «Як це працює» |
| `foto-cena` | компаніям, «Скільки це коштує» |
| `foto-odmena` | компаніям, «Що входить у винагороду» |

Кожне у двох форматах: `.webp` для сучасних браузерів і `.jpg` як запасний.
`workers.webp` / `workers.jpg` лежать у корені — вони для сторінки вакансії.

Ще бракує двох файлів:

| Файл | Звідки взяти |
|---|---|
| `img/logo.png` | логотип із шапки старого сайту |
| `img/foto-pobyt.jpg` | фото зі сторінки «Trvalý pobyt» |

Поки їх немає, сайт працює нормально: блок із відсутнім фото ховається сам,
замість логотипа показується текстовий напис PALSIR CZ.

## Що заповнити перед публікацією

1. **`common.js`, блок CONFIG угорі** — якщо заявки мають іти на пошту,
   зареєструйтесь на formspree.io і вставте адресу форми в `formEndpoint`.
   Поки поле порожнє, форма відкриває WhatsApp із готовим текстом.

2. **`privacy.html`** — усе, що підсвічене жовтим:
   номер ліцензії ÚP, дата оновлення, строк зберігання, назви сервісів.

## Як усе влаштовано

**Форма** описана один раз у `common.js` (функція `formMarkup`).
На сторінці стоїть порожній `<div data-form id="form"></div>`, у який
вона підставляється. Змінили поля в одному місці — змінилися скрізь.

**Меню** для мобільних будується автоматично з десктопного `<nav class="nav-desk">`.
Додали пункт у `nav-desk` — він зʼявився і в бургер-меню.

**Мова** визначається з мови браузера, перемикається кнопками UA/CZ/RO
і зберігається при переході між сторінками через `?l=` в адресі.

**Мапа** на сторінці контактів вантажиться лише після кліку — до цього
жодних запитів до Google не йде.

**Тексти сторінок** — унизу кожного HTML-файлу, в об'єкті `PAGE`,
трьома мовами. Додаєте новий ключ — додайте його в усі три мови.

## Позначка «Терміновий набір»

На `robota.html` угорі стоїть чорна пігулка з пульсуючою крапкою.
Текст — ключ `hotLabel` в об'єкті `PAGE` унизу файлу, трьома мовами.

Щоб прибрати позначку, коли набір не терміновий, видаліть із `robota.html`
цей рядок:

    <span class="tag hot"><span class="dot"></span><span data-i="hotLabel"></span></span>

Локація поруч залишиться на місці. Щоб повернути — вставте рядок назад.
